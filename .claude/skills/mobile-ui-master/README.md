# mobile-ui-master

A source-grounded master skill for designing mobile interfaces from use cases and product documentation **without turning requirements or guidelines into rigid screen templates**.

## Core philosophy

```text
Use Case = truth
First Glance = meaning
Scan Pattern = direction
Creative Composition = form
References = discipline / critique
```

The skill explicitly inserts a **Perceptual Reasoning** layer between product requirements and UI architecture.

The agent must answer:

- What should win the first glance?
- What should the user understand immediately?
- Where should attention move next?
- What should remain supporting or peripheral?
- When should the CTA become dominant?

Only then should it choose composition, interaction, components, tokens, and styling.

## Workflow

```text
Evidence / Use Case Truth
-> First Glance hypothesis
-> Scan / Attention Architecture
-> divergent mental models
-> selected creative thesis
-> State + Interaction integrity
-> Screen Architecture realization
-> Design-system mapping
-> Platform + Accessibility critique
-> Motion + Engineering critique
-> Use-case + Perceptual fidelity gates
```

## Reference philosophy

`references/` are **critic frameworks, not layout autopilot**.

The key new reference is:

- `00-perceptual-reasoning.md` — First Glance, Scan Pattern, Attention Architecture, interaction gravity, visual rhythm, state-sensitive attention.

The other references challenge the chosen direction for UX, architecture, color, accessibility, native behavior, scalability, motion, validation, collaboration, and handoff quality.

Explicit business rules, accessibility-critical requirements, safety constraints, and mandatory native behavior remain non-negotiable.

## Recommended use

Invoke `mobile-ui-master` for:

- use case -> original mobile UI design;
- requirement -> perceptually intentional screen specification;
- redesign while preserving product/business truth;
- Figma design briefs;
- mobile UI critique;
- design-system-aware composition;
- adaptation across iPhone, iPad, watch and widget surfaces;
- implementation handoff.

See `examples/test-prompt.md` for a smoke test focused on First Glance and Scan Pattern reasoning.
